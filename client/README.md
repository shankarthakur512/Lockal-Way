
# Lockal Way Client

Vite + React frontend for Lockal Way.

## Development
- `npm run dev`
- `npm run build`

## Browser QA
- `npm run test:e2e`
- `npm run test:e2e:headed`
- `npm run test:e2e:debug`

The Playwright suite targets `vite dev` and exercises:
- auth sign up, sign in, and log out
- home page smoke
- home search to search results to detail pages
